Para obter estatísticas completas da API SportsAPI Pro, você precisará usar os endpoints V2 específicos para cada esporte, que oferecem dados mais ricos.

Aqui está um guia geral sobre como você pode obter estatísticas completas, com exemplos para Futebol (Football V2) e Basquete (Basketball V2), que são esportes com cobertura detalhada:

1. Escolha o Esporte e a Versão da API:

Para estatísticas completas, a V2 é a versão recomendada.
Determine o esporte (ex: football, basketball, tennis).
A URL base será https://v2.{sport}.sportsapipro.com.
2. Obtenha o ID do Evento (Partida):

Primeiro, você precisará do id da partida para a qual deseja as estatísticas. Você pode obtê-lo de endpoints como:
/api/live (para partidas ao vivo)
/api/today (para partidas de hoje)
/api/schedule/:date (para partidas em uma data específica)
/api/search?q={query} (para pesquisar partidas, times ou jogadores)
Exemplo de resposta de /api/live (para obter o id do evento):


{
  "events": [
    {
      "id": 12345678, // Este é o ID que você precisará
      "homeTeam": { "id": 42, "name": "Arsenal" },
      "awayTeam": { "id": 38, "name": "Chelsea" },
      // ... outros detalhes
    }
  ]
}
3. Use Endpoints Específicos para Estatísticas:

Uma vez que você tenha o id do evento, você pode usar os seguintes endpoints para obter diferentes tipos de estatísticas.

Exemplo para Futebol (Football V2):
Estatísticas da Partida (geral):

GET /api/match/:matchId/statistics
Este endpoint geralmente fornece estatísticas agregadas da partida, como posse de bola, chutes a gol, faltas, cartões, etc.

Exemplo cURL:


curl -H "x-api-key: YOUR_API_KEY" \
  "https://v2.football.sportsapipro.com/api/match/12345678/statistics"
Incidentes da Partida (gols, cartões, substituições):

GET /api/match/:matchId/incidents
Exemplo cURL:


curl -H "x-api-key: [redacted] \
  "https://v2.football.sportsapipro.com/api/match/12345678/incidents"
Escalações (Lineups):

GET /api/match/:matchId/lineups
Exemplo cURL:


curl -H "x-api-key: YOUR_API_KEY" \
  "https://v2.football.sportsapipro.com/api/match/12345678/lineups"
Estatísticas de Jogadores (dentro de uma partida): Muitas vezes, as estatísticas de jogadores para uma partida específica são incluídas nos endpoints de lineups ou statistics, ou há endpoints dedicados como:

GET /api/match/:matchId/player-statistics
(Verifique a documentação específica do esporte para a disponibilidade exata deste endpoint).

Exemplo para Basquete (Basketball V2):
Estatísticas da Partida (geral):

GET /api/match/:matchId/statistics
Isso incluirá estatísticas como pontos, rebotes, assistências, roubos, tocos, etc.

Exemplo cURL:


curl -H "x-api-key: [redacted] \
  "https://v2.basketball.sportsapipro.com/api/match/12345678/statistics"
Escalações (Lineups) e Estatísticas de Jogadores:

GET /api/match/:matchId/lineups
Este endpoint para basquete geralmente inclui as estatísticas individuais dos jogadores para a partida.

Exemplo cURL:


curl -H "x-api-key: [redacted] \
  "https://v2.basketball.sportsapipro.com/api/match/12345678/lineups"
Dicas Importantes:

Documentação Específica do Esporte: Cada esporte na V2 tem seus próprios endpoints e estruturas de dados. Sempre consulte a documentação específica para o esporte que você está interessado (ex: Football V2 API Overview, Basketball V2 API Overview).
x-api-key: Lembre-se de incluir seu x-api-key em todos os cabeçalhos das requisições.
IDs: Certifique-se de que os IDs que você está usando (para partidas, times, etc.) são válidos para o esporte e a versão da API que você está consultando.
Cobertura de Dados: A profundidade das estatísticas pode variar dependendo da liga e do nível da competição (Tier Premium, Full, Standard, Basic). Ligas de alto nível geralmente têm as estatísticas mais detalhadas.
Se você tiver um esporte específico em mente, posso fornecer exemplos mais direcionados!
